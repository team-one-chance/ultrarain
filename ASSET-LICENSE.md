## Scope in the GameMaker project

Licensing follows the content, not just its folder or file extension:

| Content | Coverage |
| --- | --- |
| Original GML in `scripts/`, object events in `objects/`, and room or instance creation code in `rooms/` | PolyForm Noncommercial 1.0.0 in [LICENSE](LICENSE) |
| Original shader programs in `shaders/` and programming tools/scripts elsewhere in the repository | PolyForm Noncommercial 1.0.0 |

| Third-party materials, including fonts and GameMaker components | Their respective owners' terms; neither Team One Chance license grants rights to them |

A `.yy` file can contain both programming metadata and protected creative content. For example, a room's technical resource references do not make its authored tile layout available under the code license. Likewise, a sprite's technical settings do not license its animation artwork. Distributing code does not automatically permit copying an entire mixed resource or a playable build containing protected assets. Separate protected content from code when distributing a fork or patch.

## Local modding

Team One Chance permits noncommercial local modification of its original assets in a legitimate installation of ULTRARAIN for community modding, including total conversions. You may distribute independently created mod content and patch files that do not redistribute protected original assets. See [MODDING.md](MODDING.md).

## Third-party materials and ownership review

No ownership is claimed over third-party artwork, audio, fonts, GameMaker software, or other material Team One Chance does not own. Existing third-party notices and obligations must be preserved; missing attribution does not make material Team One Chance's property or grant permission to use it.

The repository does not currently provide a complete provenance inventory. In particular, `fonts/f_Console/f_Console.yy` identifies Consolas and `fonts/f_Console/f_Console.png` contains a font atlas. Confirm the applicable font permissions for distributing that atlas; it is not covered by Team One Chance's asset notice. Audio and other imported or externally generated artwork also need their source and applicable terms confirmed. These notices do not resolve those questions or relicense uncertain material.
